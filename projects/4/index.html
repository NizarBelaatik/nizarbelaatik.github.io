Twitch Channel Points TTS (Text-to-Speech)

Developed a Twitch Channel Points TTS (Text-to-Speech) application that allows streamers to convert messages redeemed by viewers using channel points into speech. This enhances audience interaction by giving a voice to viewers during live streams.

2020 Software Development Freelance Software Dev

Role & Responsibilities

Designed and developed the entire application, from initial concept to final deployment.

    Implemented and tested the TTS functionality using PySide2.QtTextToSpeech.

      Integrated Selenium for real-time monitoring of channel points redemptions.

        Developed the words filter and speed adjustment features.

          Packaged the application for cross-platform distribution using PyInstaller.

            Key Features

            Text-to-Speech Integration:

            • Converts viewer messages redeemed with channel points into speech using the PySide2.QtTextToSpeech module.

            Twitch Channel Points Integration:

            • Automatically detects when channel points are redeemed and triggers the TTS function.

            Words Filter:

            • Includes a customizable filter to block inappropriate or unwanted words from being spoken.

            Adjustable TTS Speed:

            • Allows streamers to control the speed of the speech, offering a more personalized viewer experience.

            Customizable Voices:

            • Streamers can select different voices and adjust speech rate and pitch.

            Cross-Platform Support:

            • Packaged into a standalone executable using PyInstaller for easy deployment on any platform.
